Welcome to CityScaLES's Documentation!
========================================

CityScaLES is a scalable multi-GPU large-eddy simulation (LES)
engine for city-scale airflow and heat transfer. It supports 
large-scale simulations using MPI and CUDA on multiple NVIDIA GPUs.

.. note::

   This documentation covers CityScaLES and is under active development.
